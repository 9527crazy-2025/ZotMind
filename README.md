## ✨ 简介

ZotMind 是一款专为 Zotero 打造的 **AI 辅助文献阅读助手** 插件。通过深度集成各类主流大语言模型（LLMs），它将 AI 辅助分析能力无缝嵌入到您的日常文献阅读体验中。插件提供基于 RAG 的本地知识库构建、跨文献语义搜索、支持多级上下文的智能对话（ChatPDF），以及便捷的悬浮划词增强助手。无论是精读单篇长文，还是快速在多篇文献中梳理核心概念，ZotMind 都能为您提供高效的辅助阅读支持。

## 🚀 核心功能

### 🔍 RAG 本地知识库与语义搜索

打破传统关键词搜索的局限，让文献库“听懂自然语言”。
- **文献库向量化 (Embedding)**：支持对 Zotero 全库或指定文件夹的内容进行向量化，构建专属的智能知识库。提供任务面板实时查看后台向量化进度。
- **混合语义搜索**：结合语义搜索与关键词匹配，在条目面板一键调用，帮助您快速精准定位所需的核心知识点和段落，大幅提升文献查阅准度。
- **语义定位与片段高亮**：输入自然语言搜索内容，即可匹配语义最相关的文献；支持双击搜索结果直接跳转到对应文献，并自动高亮相关联的片段，让关键内容一目了然。

### 💬 ChatPDF 智能聊天侧边栏

您的私人 AI 学术助教，随时解答关于文献的任何问题。
- **多维度上下文问答**：
  - **基础问答**：基于当前打开的单篇 PDF 直接提问。
  - **多文献联动 (`#`)**：输入 `#` 或点击图标，快速添加单篇或多篇关联文献作为上下文参考。
  - **领域级问答 (`@`)**：输入 `@` 或点击图标，一键调取整个文件夹的向量化数据作为对话上下文，实现针对特定领域的专业问答。
- **句级引用与溯源**：LLM 在给出结论的同时，自动附上该结论的依据来源——即论文中的具体片段，并提供可点击的依据链接；点击链接即可跳转到 PDF 中对应的片段并高亮显示，让每一个观点都有据可查。
- **截图提问**：阅读复杂公式、表格时的贴心工具，无需手动输入即可让 AI 看懂图片内容，通过截图方式将论文中的公式或表格发送给 LLM 进行分析，便于快速理解复杂图表与数学推导，适合处理公式、表格、图表等难以用纯文字描述的信息。
- **快捷指令 (`/`)**：输入 `/` 一键调出预设 Prompt，告别重复劳动。
- **思维导图一键生成**：点击思维导图快捷指令即可为当前论文生成结构化的思维导图，支持双击放大查看，帮助快速梳理文章框架与核心逻辑。
- **深度思考与模型无缝切换**：面对复杂学术逻辑推理时，可随时开启“深度思考”模式获得更严谨的答案；对话过程中支持随时无缝切换正在使用的 AI 大模型。
- **完善的会话体验**：提供预置问题快速上手，并支持会话的新建、历史记录查看与保存清理。

### 🖥️ WebChat 模式（节省 Token 费用）

- 通过浏览器扩展（[ZotMindBridge](https://github.com/9527crazy-2025/ZotMindBridge)）将问题和论文内容发送到 LLM 网页端，并自动回传 LLM 响应到 ZotMind 插件，实现与网页版 AI 的无缝对接。
- 当前支持 DeepSeek / ChatGPT，在享受完整对话能力的同时有效节省 Token 费用。

### ⚡ 沉浸式划词助手

阅读过程中的得力助手，选中文字即可触发悬浮工具条，无需打断阅读心流。
- **常用快捷操作**：一键执行翻译选中段落、解释专业术语、精简总结段落或语法润色等常用操作。
- **无缝联动 ChatPDF**：点击“提问”即可将选中的重点段落发送至聊天侧边栏输入框，并自动展开侧边栏，便于结合上下文深度追问。
- **个性化自定义工具**：支持根据您的专属研究习惯添加自定义 Prompt 工具，并可配置极具个性的功能图标。

### 🤖 灵活的 AI 模型配置

- **全面兼容 OpenAI 格式接口**：轻松接入硅基流动、DeepSeek、Gemini、Ollama、OpenAI、阿里百炼等海内外主流模型。
- **自定义参数**：支持自定义 Temperature、Max Tokens 以及 System Prompt 等核心参数。

### 📝 Obsidian 笔记联动导出 (可选)

- 支持基于 Markdown 模板将 Zotero 笔记及 AI 问答提取的内容结构化导出到 Obsidian。
- 支持高级变量配置（如使用 `{{year}}-{{title}}.md` 自定义笔记文件名）。
- 灵活配置导出目标目录与模板路径，轻松打造您的第二大脑。

## 🔧 安装方式

1. 确保您的系统已安装 **Zotero 7 及以上版本**。
2. 前往 [Releases](../../releases) 页面下载最新的 `.xpi` 插件安装包。
3. 打开 Zotero → `工具` → `插件`。
4. 点击右上角齿轮图标，选择 `从文件安装插件`（或直接将 `.xpi` 文件拖入插件窗口）。
5. 重启 Zotero 即可生效。

## ⚙️ 快速配置

1. 打开 Zotero → 菜单栏 `工具` → `ZotMind 设置`。
2. **AI 模型配置**：在 `AI功能` 标签页选择模型提供商，填入 API Key（亦可点击 `+自定义` 添加专属平台）。配置 Chat Model 和 Embedding 模型。
3. **测试连接**：点击 `测试连接`，确保您的 API 连通正常。
4. **快捷命令与划词助手**：在对应的设置页面自定义常用 Prompt 和快捷操作按钮。
5. **笔记管理（可选）**：配置您的 Obsidian 模板路径和导出格式。
